# Umbrales de ingeniería vs umbrales del curso

**Metas internas elegidas por el equipo:** salud observada >=99%, análisis OK >=99%, alertas publicadas >=99%, envíos ACK >=99%, P95 análisis <=500ms, P95 alerta <=1000ms. Se pueden revisar tras establecer línea base real; documentar versión y fecha del cambio.

**Umbrales que sí exige la Entrega 4:** UptimeRobot >=99% durante 7 días con status pública, PageSpeed móvil Performance >=70 y Accessibility >=80, flujo del monitor sin bloqueos y con aislamiento, README completo. Las equivalencias se someten a aprobación; no se reemplazan unilateralmente.
